# MeetRec 1.6.1

Windows 10 2004+ x64 / Windows 11 x64 · 便携版 · 内置 ffmpeg + ffprobe · 无需管理员权限

MeetRec 1.6.1 是 1.6.0 的补丁版本，新增**实时字幕浮层的自由拖动**，其余录制、音频、
转录、翻译和模型下载行为保持不变。

## 1.6.1 变更

### 实时字幕浮层可拖动

- 浮层右上角新增**拖动点**（两列共六个圆点）。鼠标移上去会显示移动光标，按住拖动即可
  调整字幕位置。
- **双击拖动点**恢复所选的对齐位置（底部居中 / 顶部居中 / 左下角 / 右下角）。
- 除拖动点外，浮层其余部分仍为**点击穿透**，不会挡住被录制窗口里的按钮或聊天区域。
- 拖动后的位置保存在 `settings.json`（`captionOffsetX` / `captionOffsetY`），跨录制生效，
  重启程序后仍然保留；在「设置 → 字幕 → 位置」中切换对齐方式时自动重置。
- 字幕文字右侧预留了拖动点空间，长句不会与圆点重叠。
- 字幕设置页、README、中英文用户手册和截图已同步更新。
- 新增开发/QA 命令 `MeetRec.exe --caption-overlay-test [秒数]`：打开一个静态字幕浮层，
  无需录制或语音模型即可测试拖动和点击穿透。

### 分发方式变更

- 从 1.6.1 起不再随 GitHub Release 发布 `MeetRec-<版本>-win64-speech-model.zip`。
  模型由应用在首次开启转录时下载并校验，也可手动放置到 `models\sensevoice\`。
- 主安装包保持轻量，转录运行时 DLL 仍随主包分发。

### 兼容性

- 不改变录制、音频混音、转录、实时翻译、模型下载和压缩流程。
- 1.6.0 的 `settings.json`、录制文件、SRT/TXT 和模型目录完全兼容；新增的偏移字段缺省为 0。
- 版本号 1.6.1.0。

## 验证

- Release / Debug 构建通过（Warning Level 4 + TreatWarningAsError），**124 个单元测试全部通过**。
- 实际鼠标拖动静态字幕浮层：浮层按拖动距离移动，偏移正确写入设置。
- 双击拖动点：浮层回到所选对齐位置，偏移归零。
- 点击字幕文字区域：点击落到下层窗口，确认点击穿透未受影响。
- 中英文设置页的拖动提示完整显示，无截断。

## 下载与安装

资产：

- `MeetRec-1.6.1-win64-with-ffmpeg.zip`（主程序 + ffmpeg + 转录运行时）
- `SHA256SUMS.txt`

1. 解压主包到一个可写目录（不要只移动 exe）。
2. 双击 `MeetRec.exe`。无需安装、无需管理员、无需虚拟显示器驱动。
3. 在「设置 → 字幕」中开启转录，并启用系统声音或麦克风。首次开启会由程序内下载语音模型
   （约 155 MB，带进度条和取消），**不再随 Release 提供独立模型包**。
4. 离线环境可手动把模型文件放到 `models\sensevoice\`，或用 `VSR_SPEECH_MODEL_DIR`
   指向已有的模型目录。

`ffmpeg.exe`、`ffprobe.exe`、`sherpa-onnx-c-api.dll`、`onnxruntime*.dll` 必须与
`MeetRec.exe` 同目录；程序会自动发现。设置与日志位于 `%LOCALAPPDATA%\VirtualScreenRecorder`。

## 系统要求

- Windows 10 2004 (build 19041) 或更高版本，x64；或 Windows 11 x64
- Direct3D 11 显卡（录制硬件编码需要可用的 QSV / NVENC / AMF，软件编码不需要）
- 不需要管理员权限、不需要 VC++ 运行库、不需要单独安装 ffmpeg

## 已知限制

- 字幕为句级，不是逐字实时；连续发言最多 10 秒强制断句。
- 拖动点只在浮层显示时可操作；暂停或最小化目标窗口时浮层隐藏。
- 拖动位置按逻辑像素保存，显示器 DPI 改变后位置会按新 DPI 换算。
- 实时翻译使用 Bing/Edge 免费公共接口，可能受网络、限流或服务调整影响；失败时保留原文。
- 字幕浮层是置顶窗口，共享整个桌面时对方也能看到；它不会进入 MP4。
